# 2026-08-15 工作记录

## Godot 项目上传 GitHub

### 完成内容
1. 完善 `.gitignore` — 在 Godot 默认基础上添加了 C#/.NET 忽略规则（bin/、obj/、*.user 等）、OS 忽略、IDE 忽略
2. 修正 `.gitignore` 错误 — 最初错误地添加了 `*.import` 规则，Godot 4 中 `.import` 文件应提交到 Git（包含资源导入配置），已移除该规则
3. Git 初始化 — `git init -b main`，首次提交包含 7 个文件
4. 安装 GitHub CLI (gh) — 通过 winget 安装 v2.97.0
5. GitHub 认证 — 使用 Personal Access Token (fine-grained PAT) 认证
6. 创建 GitHub 仓库 — `gh repo create project-market-economy --public`
7. 推送代码 — 成功推送到 https://github.com/CangNiMa/project-market-economy

### 注意事项
- 用户网络环境直连 GitHub 不稳定，需要代理/VPN
- `gh auth login --web` 设备认证流程因网络间歇性中断反复失败，最终改用 PAT 方式认证
- Fine-grained PAT 推送代码需要 **Contents: Read and write** 权限，仅有 Administration 权限会返回 403
- Git 凭证需通过 `gh auth setup-git` 配置才能使用 gh 的 token
- GitHub CLI 安装路径：`C:\Program Files\GitHub CLI\gh.exe`，需要手动加入 PATH
